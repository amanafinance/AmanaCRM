# Автотесты Amana CRM

Проверяют CRM в настоящем браузере на копии базы Firebase (эмулятор): деньги, инвесторов,
синхронизацию двух устройств, клиентов, безопасность и все страницы на ПК и телефоне.
Настоящая база при этом не используется.

Запускаются сами в GitHub (вкладка **Actions**) на каждое изменение. Зелёная галочка —
всё в порядке, красный крестик — что-то сломалось, изменение публиковать нельзя.

## Запуск на своём компьютере

Нужны Node.js 22 и Java 21.

```
cd tests
npm ci
npx playwright install chromium
npm test
```

Один набор: запустите эмулятор (`npx firebase emulators:start --only firestore,auth --project amana-crm-16033`)
и в другом окне `node run.mjs money`.

### На своём сервере (PocketBase)

Те же наборы можно прогнать на локальной копии своего сервера: Java и эмулятор не нужны.

```
cd tests
./get-pocketbase.sh          # скачивает PocketBase в tests/.pb/ (с проверкой контрольной суммы)
CRM_DB=pb node run.mjs       # или один набор: CRM_DB=pb node run.mjs money
```

В GitHub проверки идут на обеих базах сразу: `test (fb)` и `test (pb)`.

Наборы: `pages`, `money`, `investors`, `sync`, `people`, `numbers`, `backup`, `security`, `ui`, `interface`, `devices`, `design`, `speed` (папка `suites/`).

`design` проверяет дизайн-систему на всех страницах и окнах, на телефоне и компьютере, в обеих темах:
на телефоне всё нажимаемое не меньше 44 px, текст не мельче 12 px, контраст текста по норме,
размеры шрифтов только из шкалы 12 · 14 · 16 · 20 · 24 · 32, фильтры в одну строку, окна с закреплённой шапкой и кнопками;
графики в одном стиле (ось, сетка, легенда под графиком, подсказка по наведению и нажатию).

## Скриншоты всех экранов

`npx firebase emulators:exec --only firestore,auth --project amana-crm-16033 "node audit.mjs audit-out"` —
снимки всех страниц и окон (телефон 390×844 и компьютер 1280×850, обе темы) и `report.json` с замерами
в папке `tests/audit-out`. Чтобы снимки были с настоящими шрифтами, положите их локальную копию в папку
и укажите её в `FONTS_DIR` (без неё шрифт будет запасной).
