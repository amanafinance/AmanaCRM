# Автотесты Amana CRM

Проверяют CRM в Chromium на отдельной временной базе PocketBase: договоры,
деньги, инвесторов, синхронизацию устройств, права, резервные копии и интерфейс.
Рабочая база не используется. После завершения временная база удаляется.

Проверки запускаются в GitHub Actions при pull request и изменении main.

## Запуск

Нужны Node.js 22 и Python 3 (для локального HTTP-сервера). Из папки `tests`:

```
npm ci
npx playwright install chromium
npm test
```

`npm test` скачивает PocketBase 0.40.6 с проверкой контрольной суммы и запускает
все 17 наборов. После установки бинарного файла один набор запускается так:

```
node run.mjs money
```

Наборы: `hardening`, `pages`, `money`, `investors`, `sync`, `people`, `filters`, `longtext`,
`numbers`, `backup`, `staff`, `security`, `ui`, `interface`, `devices`, `design`, `speed`.

## Снимки экранов

```
./get-pocketbase.sh
node audit.mjs audit-out
node uiaudit.mjs ui-out
```

Скрипты используют свою временную базу. Для локальных шрифтов можно задать
`FONTS_DIR`. Для установленного системного браузера — `CHROMIUM_PATH`.
`design` проверяет размеры кнопок и текста, контраст и графики в обеих темах.


`hardening` проверяет вход по почте и паролю, отключённый вход с кодом,
запреты прямых запросов, конкурентные выводы, отсутствие почтовой рассылки,
выход в нескольких вкладках и удаление локальной базы. `backup` проверяет
ручные копии с паролем и без, восстановление и отказ при неверном пароле.
Переменная `AMANA_TEST=1` включает тестовые маршруты; на рабочем сервере её
быть не должно.
